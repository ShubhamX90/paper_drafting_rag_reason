############################
VERDICT HEURISTICS & THRESHOLDS
############################

- supports: the snippet directly answers the query with an explicit, decisive claim.
- partially supports: on-topic but incomplete, hedged, indirect, or missing a required detail.
- irrelevant: not useful for answering the query.

1) Threshold queries:
  - For "over/at least X?": a span stating a maximum/ceiling/"at most"/a range whose upper bound <= X can be decisive.
  - Categorical statements ("cannot exceed X") can be supports if clearly stated.
  - Hedged language ("may/might/probably/likely") alone -> partially supports unless a decisive bound is stated.

2) Span preference:
  - If multiple candidate facts exist, choose the most specific snippet content containing decisive values/dates/names.

3) Missing required details:
  - If the query requires a date/number/name and the snippet lacks it: do not mark supports.
    Use partially supports if on-topic, else irrelevant.

4) "Next/most recent/latest":
  - supports only if the snippet explicitly identifies the earliest/"next"/"most recent/latest".
  - Lists without a clear "next/most recent/latest" -> partially supports.
  - Mere description without "latest/next/most recent" language -> partially supports.

5) Comparisons/opinions:
  - supports if a clear overall claim answers the general case.
  - partially supports if limited to a subset/region/industry/conditional case or small samples.

6) Negative/inconclusive evidence:
  - "No evidence / not enough evidence / inconclusive" -> partially supports (never supports).

7) Date-specific queries:
  - supports only with a full calendar date or complete date range.
  - Year-only/vague/contradictory dates -> partially supports.

8) Factual identification ("Who/What/Where/When"):
  - supports if the snippet names the entity and the required status (current/latest/official) clearly.
  - Otherwise partially supports.

9) Exact count / tally questions:
  - If the retrieved snippets explicitly enumerate the relevant entities or give an exact count, answer with that exact count.
  - If an exact count can be derived directly from the retrieved snippets without outside knowledge, derive it carefully and answer with the exact count.
  - If the snippets show only examples, approximations, ranges, or partial lists, do not invent a precise count; say the exact count cannot be determined from the retrieved evidence.

10) Ambiguous scope:
  - Do not silently assume a country, region, organization, or time scope unless the query or evidence clearly makes that scope primary.
  - If the evidence points to more than one plausible scope, state the scope explicitly in the first sentence and answer within that scope.
  - If the query is broad and the evidence is mixed by jurisdiction or definition, do not overgeneralize from one country-specific source.

###############################################
CONFLICT TYPE DEFINITIONS (DO NOT CHANGE GIVEN LABEL)
###############################################

These definitions explain the labels. You do NOT choose among them here.

1) No conflict
  - Non-irrelevant docs agree on the key claim; differences are superficial.

2) Complementary information
  - Non-irrelevant docs add different facets, scopes, subgroups, or definitions that fit together without contradiction.

3) Conflicting opinions or research outcomes
  - Non-irrelevant docs contain incompatible claims, viewpoints, or research findings within the same scope and time window.

4) Conflict due to outdated information
  - Older and newer factual claims disagree, and newer evidence supersedes older claims.

5) Conflict due to misinformation
  - The retrieved set itself provides a clear basis to call one claim false or misleading relative to stronger retrieved evidence.

#######################
ABSTENTION POLICY (STRICT)
#######################

Abstain only if ALL docs are "irrelevant" OR the set collectively fails to address the query.
If ANY doc supports the answer, do NOT abstain; produce the best supported answer consistent with the GIVEN label.
If all docs are partially supports or irrelevant, abstain only if the partial evidence cannot form a meaningful grounded response.
Disagreement alone is not a reason to abstain.
Abstention is about inability to answer the query from the retrieved evidence, not about the presence of nuance or disagreement.
